# 会话廊 (Session Booth)

> 一个 DeepSeek Harness (DSH) 插件：在主窗口并排显示多个会话，布局持久保存。
>
> [中文版 README](./README.md) | [English README](./README_EN.md)

---

## 简介

**会话廊** 在左侧栏新增一个常驻入口，让你在主窗口中同时查看 **n 个会话**。每个会话一个分屏，互不干扰，适合并行监控多个 Agent 任务。

---

## 功能

| 功能 | 说明 |
| --- | --- |
| 左侧栏常驻入口 | 点击「会话廊」进入分屏视图 |
| 首次点击多选 | 弹出会话选择器，可勾选多个会话 |
| 分屏布局 | 1 / 2 / 4 宫格自动排列（1、2、4 个会话） |
| 每格控制 | 右上角：状态点、删除（−）、添加（+） |
| 标题栏 | 「工作区」[› 会话] 分体：点工作区名跳转当前会话，点会话名（灰底）切换同工作区会话 |
| 实时滚动 | 默认滚动到底部，流式输出时自动跟随；输入框聚焦时暂停跟随 |
| 状态点 | 完成=绿，运行中=绿闪，待处理=黄，报错=红 |
| 持久化 | 布局写入 `localStorage`，重启 DSH 后自动恢复 |

## 安装

插件目录：`session-booth/`（本仓库）。

在 DSH 中通过插件管理安装：

```
plugin_manager install_bundle C:\...\session-booth
```

> 如果默认镜像（`registry.npmmirror.com`）返回 `ERR_PNPM_NO_MATCHING_VERSION`，请改用官方源：
>
> ```
> plugin_manager install_bundle <插件目录> --registry https://registry.npmjs.org
> ```

---

## 使用

1. 点击左侧栏 **会话廊** 图标。
2. 首次进入会弹出选择器：勾选要显示的会话，点击「确认」。
3. 每个分屏标题栏：点左侧「工作区」名跳转当前会话；点右侧「› 会话」名（灰底）切换同工作区会话。
4. 每个分屏右上角：**+** 添加更多会话、**−** 移除该会话。
5. 重启 DSH 后自动恢复上次的分屏布局。

## 状态点颜色

| 状态 | 颜色 / 动效 |
| --- | --- |
| 完成 | 实心绿 `#30a46c` |
| 运行中 | 绿色渐入渐出闪烁 |
| 待处理（尚无首轮） | 黄 `#f5a623` |
| 意外终止 / 报错 | 红 `#e5484d` |
